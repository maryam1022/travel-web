# 🌍 Travel Website

A modern and responsive travel website designed to showcase travel destinations, packages, pricing, and booking information.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Travel destination cards
* Destination descriptions
* Travel package pricing
* Booking section
* Interactive booking confirmation
* Smooth animations
* Modern travel-focused UI
* User-friendly navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP
* Font Awesome

## 📱 Responsive Design

The website is designed to provide a smooth experience across different screen sizes, including:

* Desktop
* Tablet
* Mobile
